# Talha Habib ? Portfolio

A responsive, single-page portfolio for Talha Habib, a Computer Science student and full-stack developer based in Chitral, Pakistan. The site is built with plain HTML, CSS, and JavaScript and deploys as a static site on [Vercel](https://vercel.com).

## What?s on the site

- A concise introduction with GitHub, LinkedIn, WhatsApp, and CV links
- Three featured projects: an AI study assistant, an education platform, and internship work
- Background, internship experience, and a focused overview of the development toolkit
- Accessible light and dark themes, with the selected theme saved in the browser
- A Formspree contact form
- An original TH monogram for the header, footer, and browser tab
- Custom abstract interface artwork for the light theme

## Run locally

Open `index.html` in a browser, or serve the project directory with any static web server. No package installation or build step is required.

## Personalize

- Replace `t1.png` with an optimized profile image and update its alternative text in `index.html`.
- Update the project descriptions and links in `index.html` as your work evolves.
- The contact form uses a Formspree endpoint. Replace its `action` URL in `index.html` with your own endpoint if you fork this site.
- Update the printable CV source in `cv.html`, then export it to `Talha-Habib-CV.pdf`; update profile URLs in `index.html` when needed.

## Deployment

The repository is configured for static deployment on Vercel. Connect the repository and deploy from its root directory; there is no build command.
